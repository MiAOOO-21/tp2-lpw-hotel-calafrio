# Hotel Calafrio

Um curto RPG visto de cima feito com Phaser 4 para aprender a programar jogos.
Você chega a um hotel estranho no meio do deserto, ajuda os hóspedes em 5 desafios,
descobre o ponto fraco da FERA que manda no lugar e enfrenta ela numa batalha por turnos.

---

## Como rodar

1. Instale o VS Code e dentro dele a extensão **Live Server**;
2. Abra a pasta "tp2-lpw-hotel-calafrio" no VS Code;
3. Clique com o botão direito no "index.html" e escolha **open with Live Server**;
4. O jogo abre no navegador, DIVIRTA-SE!
